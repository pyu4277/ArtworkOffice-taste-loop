# 디자인 레퍼런스 서비스 목록과 쓰는 법

사용자 요청(2026-11-07): "스킬 안에서 전문적인 디자인을 그때그때 레퍼런스로 삼을 수 있도록, 이미 잘 되어 있는 디자인 레퍼런스 제공 서비스를 적극 활용하도록 유도한다."

## 언제·어떻게 (SKILL.md 3절)

1. 디자인을 정하기 전(색·글꼴·배치·모션·구성)에 아래 표에서 자료 종류에 맞는 서비스 2~3곳을 고른다.
2. 검색어를 만든다: `<자료 종류 영문> + <분위기> + <분야>` (예: `science explainer motion graphics dark`, `exhibition vertical video typography`, `research report layout`). 한국어 서비스는 한국어로.
3. 후보 8~12개를 모아 **레퍼런스 보드**를 만든다: `materials/인터뷰/레퍼런스보드_v1.md`(또는 검토 모드 HTML). 항목마다 링크 · 한 줄 요점 · **무엇을 가져올지**(색 조합 / 배치 / 글자 움직임 / 전환 방식) · 주의(라이선스, 그대로 복사 금지).
4. 검토 모드(GUI-Interview.html `review`)로 사용자가 👍/👎와 이유 칩을 고른다. 결과를 `P2.7.reference_board`(프로젝트 기록)와, 반복되면 취향 항목(P2.4 색·글꼴·배치, P2.6 움직임)에 반영한다.
5. 레퍼런스는 **영감용**이다. 이미지·영상·글꼴 파일을 가져다 쓰면 최상위 2.4절대로 `assets/`에 두고 `assets/CREDITS.md`에 출처를 적는다. 다른 사람의 디자인을 그대로 베끼지 않는다.
6. 클라우드 세션에서는 브라우저 화면을 볼 수 없다(규칙 3.1). 웹 검색·페이지 읽기로 링크와 글 설명만 모으고, 스크린샷이 필요하면 「PC에서 할 일」로 보낸다(PC에서는 ego-browser로 캡처해 보드에 붙인다).
