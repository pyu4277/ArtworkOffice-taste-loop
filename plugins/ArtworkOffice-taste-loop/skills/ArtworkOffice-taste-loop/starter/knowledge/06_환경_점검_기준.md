# 환경 점검 기준 (SKILL.md 1절 ③)

제작을 시작하기 전에 `scripts/check_env.py`(Linux·macOS·클라우드) 또는 `scripts/check_env.ps1`(Windows, 사용자가 실행해 결과를 붙여 넣음)로 아래를 점검하고, 결과 표를 계획 문서에 적는다. 점검은 **막지 않는다**. 판정은 실행 모드(SKILL.md 2절)에 따라 한다. 프로젝트마다 더 필요한 도구는 데이터 폴더의 `PROJECT.md`에 적는다.

| 도구 | 용도 | 없을 때 |
|---|---|---|
| python3 (3.8+) | 스킬 스크립트 전부 | 설치 전에는 스킬 스크립트를 못 쓴다 |
| git | 커밋·기록 | — |
| node (20+) | jsdom 검증 | 검증만 못 한다 |
| jsdom@24.1.3 | 인터뷰 페이지 검증 | `npm install --prefix /tmp/slidecheck jsdom@24.1.3` |
| kordoc | 원자료 해독(HWP·PDF 등) | 원자료가 그런 문서일 때만 필요 |
| ffmpeg · ffprobe | 영상 처리 | 영상 산출물일 때만 |
| 브라우저 화면 검수 도구 | 렌더링 확인·스크린샷 | 없으면 「못 한 것」으로 보고한다 |
| 이미지·영상 생성 도구(MCP·커넥터) | 생성 | 생성이 필요한 단위만 막힌다 |

판정 낱말: **가능** / **설치 필요**(설치하면 됨) / **원칙상 불가**(이 환경에서는 쓰지 않기로 한 것 — 알리고 사용자 승인으로 진행).

- 커넥터·MCP는 스크립트가 볼 수 없다. Claude가 자기 도구 목록에서 확인해 표에 적는다.
