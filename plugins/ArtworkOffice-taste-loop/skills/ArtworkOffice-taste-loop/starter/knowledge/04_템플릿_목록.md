# 재사용 템플릿 목록

같은 종류의 자료는 템플릿 하나로 만들고 데이터만 바꾼다. 새 템플릿을 만들면 여기에 등록한다.

| 자료 종류 | 템플릿 | 위치 | 사용법 | 단일 파일 공유본 |
|---|---|---|---|---|
| 인터뷰·검토 페이지 (반응형 사이트형 앱: 메뉴·리본·사이드 트리(접기·펼치기·선택 펼치기·검색, 질문마다 예시 줄)·크게 보기·대시보드·저장소 열람, 지난 내역을 질문에 끌어다 넣기) | GUI-Interview.html | 스킬 폴더 `GUI-Interview.html` | `scripts/build_interview.py`(저장소를 페이지 안에 넣음). 검사 `scripts/check_interview.js` | 게시용·파일용 두 판(둘 다 단일 파일) |
