# 교훈 기록 (프로젝트마다 맨 아래에 한 건 추가 — 위 기록은 고치지 않는다)

프로젝트를 마무리할 때(SKILL.md 6절) 피드백과 판정을 여기에 남긴다. 한 건의 양식:

```
### YYYY-MM-DD — <강의 폴더> / <자료 종류> (<실행 모드>)
- 차원 값: 종류 · 목적 · 대상 · 환경 · 길이 (projects/<강의폴더>.json 과 같게)
- 받은 피드백: 👍 n · 👎 n · 수정 요청 n (01_피드백_기록.md 참고)
- 판정:
  - 취향 등록: <entry id> — <한 줄> (범위, 세기)
  - 프로젝트 기록만: <결정 한 줄> (이유: 내용 의존적 / 1회성)
  - 차원 값 추가: <차원>=<값>
  - 템플릿 등록: <경로>
  - 규칙 승격 제안: <entry id> → 프로젝트 규칙 파일 <절>
  - 미반영: <제안> — 이유 (품질 위험 / 회귀 / 범위 불명확)
- 다음에 바꿀 것: <절차·질문·엔진에서 고칠 점>
```
